Guidelines

Please provide the encrypted XML assertion and the service provider's private key. We will parse and decrypt the data to process the SAML information accurately.

We will automatically populate the text fields whenever possible, but if parsing is unsuccessful you can manually provide the encrypted data (Base64), the encrypted key (Base64), the encryption algorithm (key digest), the encryption algorithm (key), the encryption algorithm (data), and the service provider private key (PKCS#1 or PKCS#8 in PEM format), so you always retain full control over the input values.

This tool is 100% client-side. We don't collect your data. Source code is available on GitHub @Puvipavan.

Got a private key in another format? Convert it to PKCS1 or PKCS8 PEM.
DER to PKCS8 Conversion:
openssl pkcs8 -inform DER -in private_key.der -outform PEM -out private_key.pem -nocrypt
